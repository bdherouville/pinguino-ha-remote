Flash the Ganymede Bridge

This installs the Ganymede Bridge firmware (Wi-Fi / MQTT / Home Assistant front-end) straight from your browser — no toolchain needed.

The installer automatically selects the right release image for the connected chip:

  • ESP32-S3: existing headless bridge firmware.
  • ESP32: touchscreen bridge firmware.
  1. Use Chrome or Edge on desktop (Web Serial).
  2. Plug the ESP32-S3 headless board or plain ESP32 touchscreen board into USB.
  3. Click Install below and pick the board serial port.
Your browser doesn't support Web Serial — use Chrome/Edge, or the command-line path in the README.

After flashing, the board exposes a Ganymede-Bridge Wi-Fi access point on first boot — connect to it, open http://192.168.4.1, and set your Wi-Fi (and optional MQTT broker for Home Assistant).

The nRF52840 board is flashed separately (UF2 drag-and-drop). The touchscreen image targets the JC2432W328 plain ESP32 board with ST7789 display and CST820 touch configured. See the project README for the full step-by-step, including the one-time nRF bootloader upgrade.
