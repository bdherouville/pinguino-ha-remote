Flash the ESP32-S3 bridge

This installs the Ganymede Bridge firmware (Wi-Fi / MQTT / Home Assistant front-end) onto an ESP32-S3 board, straight from your browser — no toolchain needed.

  1. Use Chrome or Edge on desktop (Web Serial).
  2. Plug the ESP32-S3 into USB.
  3. Click Install below and pick the USB JTAG/serial port.
Your browser doesn't support Web Serial — use Chrome/Edge, or the command-line path in the README.

After flashing, the board exposes a Ganymede-Bridge Wi-Fi access point on first boot — connect to it, open http://192.168.4.1, and set your Wi-Fi (and optional MQTT broker for Home Assistant).

The nRF52840 board is flashed separately (UF2 drag-and-drop). See the project README for the full step-by-step, including the one-time nRF bootloader upgrade.
